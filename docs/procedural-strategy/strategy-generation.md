# Generacion de estrategia

La estrategia generada es una lista de pasos prudentes:

- verificar plazo y notificacion;
- confirmar autoridad competente;
- ordenar hechos cronologicamente;
- adjuntar prueba clave;
- tratar admisibilidad antes del fondo.

Las opciones incluyen precondiciones, ventajas, desventajas, necesidades probatorias, riesgos y confianza. No hay recomendacion garantizada de resultado y no se sustituye el criterio profesional.

## Fase 9

El harness `pnpm eval:procedural-strategy` exige contraanalisis en casos no triviales. En la salida
actual se valida mediante escenarios adversos, riesgos y argumentos a evitar. Para el caso piloto de
asistencia juridica gratuita en Appenzell Ausserrhoden, la estrategia aceptable debe distinguir entre
argumentos fuertes, plausibles, dependientes de prueba y argumentos que conviene abandonar.

La confianza debe bajar si faltan documentos esenciales, si el plazo no puede calcularse, si la
jurisprudencia es escasa o si los hechos son alegados/discutidos.
