# Evaluacion de prueba

La evaluacion probatoria es mecanica y conservadora.

- `strong`: registro oficial con autenticidad confirmada.
- `moderate`: prueba confirmada de otro tipo.
- `weak`: autenticidad disputada o hecho relacionado disputado.
- `unknown`: autenticidad desconocida.

La herramienta solo vincula prueba a hechos mediante solapamiento lexical simple. Si no encuentra relacion directa devuelve `no_mapped_relevant_fact`.

No decide admisibilidad final, valor probatorio judicial ni credibilidad de testigos. Las grabaciones reciben advertencia especifica de licitud.
