# Security Threat Model

Threats covered by controls and tests include local unauthorized access, stolen machine, malware, local malicious user, software tampering, compromised provider, compromised dependency, supply chain attack, MITM, DNS poisoning, DNS rebinding, SSRF, replay, downgrade, session misuse, log leakage, error leakage, document prompt injection, malicious PDF/XML/RDF/HTML, manipulated update, exposed backup, exposed cache, symlink attack, path traversal, privilege escalation, unauthorized Claude Desktop modification and provider-based exfiltration.

Residual risk remains for host compromise, operator key custody, unavailable external scanners, and legal source outages.
