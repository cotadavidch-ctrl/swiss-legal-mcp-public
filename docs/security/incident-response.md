# Incident Response

For critical incidents:

1. Stop sensitive operations.
2. Preserve minimal evidence.
3. Invalidate credentials.
4. Block updates.
5. Isolate affected providers.
6. Verify integrity.
7. Inform the operator.
8. Rotate keys.
9. Review scope.
10. Restore a trusted version.
11. Document closure.

Do not destroy evidence automatically. Do not transmit local data without consent.
